# 🏥 Dawini — Connected Medical Platform

> A modern, secure, and scalable medical platform connecting patients, doctors, and pharmacies.

## ✨ Features
-  Role-based authentication (Patient / Doctor / Pharmacy)
-  Online appointment scheduling
-  Secure electronic medical records
-  Digital prescription management
-  Encrypted messaging
-  Teleconsultation support

## 🧱 Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite |
| Routing | React Router v6 |
| Server State | TanStack Query |
| Client State | Zustand |
| Styling | Tailwind CSS + shadcn/ui |
| Forms | React Hook Form + Zod |
| HTTP Client | Axios |

## 🚀 Getting Started

\`\`\`bash
git clone https://github.com/your-org/dawini-frontend
cd dawini-frontend
npm install
cp .env.example .env
npm run dev
\`\`\`
